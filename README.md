# Reverse Engineering Lab

A hands-on journey to master web scraping, browser automation, and reverse engineering by analyzing 50 real-world websites.

## About

This repository documents my journey of becoming a professional web scraping and browser automation engineer.
Instead of following endless tutorials, I reverse engineer one website at a time, understand how it works, and document my findings.
The goal is to develop practical skills required for freelancing, automation engineering, and building production-grade scraping systems.

## Objectives

- Master Python for scraping and automation
- Learn browser automation using Playwright
- Reverse engineer modern websites
- Understand network requests and APIs
- Practice HTTP fundamentals
- Study authentication workflows
- Learn session and cookie management
- Improve debugging and problem-solving skills
- Build a public portfolio of real-world projects

## Learning Approach

For every website, I follow the same workflow:
1. Explore the website manually.
2. Inspect the Network tab in DevTools.
3. Identify data sources.
4. Determine whether an API exists.
5. Analyze requests and responses.
6. Reproduce requests where appropriate.
7. Use Playwright when browser automation is needed.
8. Document observations, challenges, and lessons learned.
